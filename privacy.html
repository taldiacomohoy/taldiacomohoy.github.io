Privacy Policy / Política de privacidad

Last updated / Última actualización: 8 November 2026

1. Who we are

"Tal Dia Como Hoy" (the "App") is a desktop tool operated by a single individual, the owner of the YouTube channel "Tal Día Como Hoy". Contact: youtube.com/@taldiacomohoy.

2. YouTube API Services

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data the App accesses

With the channel owner's explicit OAuth consent, the App accesses only the owner's own YouTube account, using these scopes:

  • youtube.upload: to upload the owner's own videos, with title, description, tags and scheduled publication time.
  • youtube.readonly: to confirm which channel is authorised and to read that channel's public statistics (views, likes, comments) for its own videos.
  • yt-analytics.readonly: to read aggregated analytics (for example average view percentage) for the owner's own videos.

The App does not access any other user's data, comments' authors, subscribers' identities, or any personal data of viewers.

4. How data is used, stored and shared

  • Data is used only to publish the owner's videos and to produce private performance reports for the owner.
  • The OAuth token and statistics are stored only on the owner's own computer, in a local database. They are not uploaded to any server operated by the App.
  • No data is sold, rented, shared with third parties, or used for advertising.
  • The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

Statistics are kept locally for as long as the owner operates the App and can be deleted at any time by deleting the local database. Access can be revoked at any time at Google security settings (myaccount.google.com/permissions), after which the App can no longer access the account. To request deletion of any stored data, contact the e-mail above.

6. Cookies

This website does not use cookies or analytics.

Resumen en español

Esta herramienta solo accede, con permiso expreso, al canal de YouTube de su propio autor para subir sus vídeos y leer sus estadísticas. Los datos se guardan únicamente en el ordenador del autor, no se comparten ni se venden, y el permiso puede revocarse en cualquier momento en myaccount.google.com/permissions. Al usar la herramienta se aceptan las Condiciones de YouTube y se aplica la Política de privacidad de Google.
