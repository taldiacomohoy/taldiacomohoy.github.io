Qué es

Tal Día Como Hoy es un canal de YouTube de divulgación histórica. Cada vídeo cuenta un acontecimiento ocurrido en la fecha de publicación, con su fuente citada (Wikipedia) e imágenes de dominio público o con licencia libre (Wikimedia Commons), atribuidas en la descripción.

Los vídeos se producen con una herramienta privada que se ejecuta en el ordenador del autor: redacta el guion a partir de la fuente, lo verifica, genera la narración con voz sintética, monta el vídeo y lo sube al canal mediante la API oficial de YouTube.

About this application (English)

"Tal Dia Como Hoy" is a private, single-user desktop tool operated by the channel owner. It uses the YouTube Data API to upload the owner's own original videos to the owner's own channel, and the YouTube Analytics API to read that channel's performance. It has no other users, does not access anyone else's data, and does not sell or share data.
